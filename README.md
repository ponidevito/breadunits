# 🌾 Bread Units Calculator (ХО / XE)

&gt; Безкоштовний онлайн-калькулятор хлібних одиниць — швидкий розрахунок ХО для будь-якої порції їжі. Працює повністю в браузері, без реєстрації та без надсилання даних.

## ✨ Можливості

- 🧮 **Калькулятор ХО** — два режими: за продуктом зі списку або з ручним вводом вуглеводів
- ⚖️ **Гнучка норма** — облік 10 або 12 г вуглеводів на одну ХО
- 📊 **Довідкова таблиця** — кількість продукту на 1 ХО, вуглеводи на 100 г і глікемічний індекс (ГІ)
- 📱 **Повна адаптивність** — зручна робота на смартфоні, планшеті та десктопі
- 🔒 **Приватність** — усі розрахунки виконуються локально в браузері, дані нікуди не надсилаються
- 🆓 **Без реєстрації** — жодних облікових записів чи підписок
- 🎨 **Сучасний UI** — чистий інтуїтивний інтерфейс з миттєвим результатом

## 🚀 Швидкий старт

```bash
# 1. Клонувати репозиторій
git clone https://github.com/ponidevito/breadunits.git
cd breadunits

# 2. Встановити залежності
npm install

# 3. Запустити dev-режим (з hot-reload через Browser Sync)
npm run dev

# 4. Збірка для продакшну
npm run build
```

## 📁 Структура проєкту

```
breadunits/
├── src/            # Вихідний код (HTML-частини, SCSS, JS, зображення)
├── gulpfile.js     # Конфігурація Gulp-збірки

```

## 🌐 Деплой

Проєкт автоматично деплоється на **Netlify** (див. `netlify.toml`).
